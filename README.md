# 📖 About This Repository

Welcome to **Git Learning**!

This repository is a complete reference for learning **Git** and **GitHub** from scratch. It is designed to help beginners build a strong foundation while also covering advanced concepts used by professional software engineering teams.

Instead of only listing commands, this repository explains:

* Why each command exists
* When to use it
* Common mistakes
* Real-world examples
* Team collaboration workflows
* Best practices followed in the industry

# ⚡ Quick Git Commands

## Configure Git

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global --list
```

---

## Create Repository

```bash
git init
git status
```

---

## Stage Files

```bash
git add .
git add filename
```

---

## Commit Changes

```bash
git commit -m "Initial commit"
```

---

## View History

```bash
git log
git log --oneline
git log --graph --all
```

---

## Branching

```bash
git branch
git switch -c feature/login
git merge feature/login
```

---

## Remote Repository

```bash
git remote add origin <repository-url>
git push -u origin main
git pull origin main
git fetch origin
```

---

## GitHub CLI

```bash
gh auth login
gh auth status
gh repo create
gh repo list
gh repo view
```
