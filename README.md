# 📖 About

Welcome to **Git Learning**!

This repository is a complete Git and GitHub learning handbook designed for:

Unlike traditional cheat sheets, this repository focuses on **understanding Git**, not just memorizing commands.

Each lesson explains:

# ⚡ Essential Git Commands

## Configure Git

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

## Create a Repository

```bash
git init
git status
```

## Stage & Commit

```bash
git add .
git commit -m "Initial commit"
```

## Branching

```bash
git switch -c feature/login
git merge feature/login
```

## Remote Repository

```bash
git remote add origin <repository-url>
git push -u origin main
git pull
```

## GitHub CLI

```bash
gh auth login
gh repo create
gh repo list
```
